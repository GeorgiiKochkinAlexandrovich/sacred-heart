# Запуск Sacred Heart в mainnet (настоящие деньги)

Все команды — в Ubuntu из папки проекта:
```bash
cd /mnt/c/Users/User/Desktop/help-split
```

## 0. Что нужно до запуска

- [ ] **Хотя бы один настоящий получатель.** Фонд или клиника письменно подтвердили свой адрес кошелька Solana.
  Тестовые кошельки из `test-wallets/` в mainnet использовать нельзя.
- [ ] **Около 5.5 SOL** на момент запуска. Во время загрузки сеть временно держит двойной залог; примерно
  половина вернётся сразу после. Итоговый расход — около 2.6 SOL: залог за место под контракт (возвращается,
  если контракт когда-нибудь закрыть) плюс комиссии и создание направлений.
- [ ] **Ссылка Helius для mainnet** (helius.dev → сеть Mainnet → RPC URL). Никому не показывать.
- [ ] Желательно: независимый аудит (см. `SECURITY-REVIEW.md`).

## 1. Проверить исправленный контракт в devnet

Контракт после проверки безопасности изменился, поэтому сначала обновляем devnet и тестируем:
```bash
bash upgrade-devnet.sh "https://devnet.helius-rpc.com/?api-key=ВАШ_КЛЮЧ"
bash publish-github.sh
```
Потом сделайте тестовое пожертвование на сайте (минимум теперь 0.01 SOL).

## 2. Запустить контракт в mainnet

```bash
bash mainnet/deploy-mainnet.sh "https://mainnet.helius-rpc.com/?api-key=ВАШ_КЛЮЧ"
```
Скрипт:
1. создаст **новый кошелёк админа** только для mainnet и покажет 12 слов — **запишите их на бумагу**,
   не фотографируйте и не делайте скриншот;
2. попросит пополнить этот кошелёк на 5.5 SOL (с биржи или из Trust Wallet) и запустить скрипт снова;
3. спросит подтверждение — нужно написать `MAINNET`;
4. загрузит контракт и создаст конфигурацию: 15% → Trust Wallet `DdTPV7…EibYbM`.

## 3. Добавить получателей

Заполните `mainnet/causes.json`. Одно направление — один блок:
```json
{
  "name": "Лечение зависимостей и психическое здоровье",
  "category": "addictionMentalHealth",
  "beneficiary": "АДРЕС_КОШЕЛЬКА_ФОНДА",
  "partner": "Название фонда",
  "proof": "ссылка или дата письма, где фонд подтвердил адрес",
  "status": "new"
}
```
`category`: `addictionMentalHealth`, `lostDocuments`, `ukraineWar` или `surgery`.

Сначала проверка (ничего не отправляет):
```bash
bash mainnet/add-causes.sh "https://mainnet.helius-rpc.com/?api-key=ВАШ_КЛЮЧ"
```
Если всё верно — отправка:
```bash
bash mainnet/add-causes.sh "https://mainnet.helius-rpc.com/?api-key=ВАШ_КЛЮЧ" yes
```
Скрипт проверит адреса, не даст указать получателем ваш кошелёк и отметит добавленные направления в файле.

## 4. Передать управление мультиподписи (Squads)

1. Откройте **app.squads.so**, создайте мультиподпись, например «2 из 3»: ваш Trust Wallet, Phantom
   и кошелёк доверенного человека или второе устройство.
2. Скопируйте адрес **Vault** (хранилища) — не адрес самой мультиподписи.
3. Запустите:
```bash
bash mainnet/handover-multisig.sh "https://mainnet.helius-rpc.com/?api-key=ВАШ_КЛЮЧ" АДРЕС_VAULT
```
После этого добавлять направления, менять кошелёк 15% и обновлять код можно только через Squads
с подписями участников. Это главная защита: даже если украдут один ключ, контракт в безопасности.

## 5. Переключить сайт на mainnet

1. В helius.dev создайте **второй** ключ для сайта и в **Access control** разрешите только домены
   `sacredheart.help` и `sacred-heart-blond.vercel.app`. Ключ сайта виден всем — ограничение по домену
   не даст его использовать на других сайтах.
2. В `app/config.js` замените:
```js
cluster: "mainnet-beta",
rpc: "https://mainnet.helius-rpc.com/?api-key=КЛЮЧ_ДЛЯ_САЙТА",
```
3. `bash publish-github.sh` — Vercel обновит сайт. Плашка «Тестовая версия» исчезнет сама.

## 6. Проверка после запуска

- Сделайте первое пожертвование 0.01 SOL и откройте транзакцию в Explorer: 85% получателю, 15% на Trust Wallet.
- В Trust Wallet должны прийти настоящие 0.0015 SOL.
